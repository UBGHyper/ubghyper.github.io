Contact

UBGHyper is a small, independent project. The quickest way to reach us — for anything from a broken game to a removal request — is through our GitHub project.

Get in touch

Open an issue or start a discussion on our GitHub repository. It's public, it's monitored, and it's the fastest way to get a response. Please include as much detail as you can — a link to the specific page usually helps most.

Report a broken game

Found a game that won't load, shows a black screen, or crashes? Let us know which game and what happened. We test and remove broken games regularly, and a quick report speeds that up. Include the game's page URL if you can — for example, ubghyper.github.io/games/Slope.html.

Request a game

Want a specific game added? We're always expanding the library, especially with quality web ports and hard-to-find titles. Send the name (and a link to a working version if you have one) and we'll see if we can host it.

Content removal & copyright

UBGHyper embeds and links games from various sources. If you're a rights holder and believe your content is hosted or linked here without authorisation, contact us via GitHub with:

  • The exact page(s) or game(s) in question (URLs).
  • Identification of the copyrighted work.
  • Your relationship to the work (owner or authorised agent).
  • Your contact details.

We take these requests seriously and will remove or disable access to validly-identified content promptly.

Feedback & bugs

Ideas, layout bugs, or general feedback are all welcome. UBGHyper is built in the open, and a lot of its improvements come straight from player suggestions. See what's changed on the About page changelog.

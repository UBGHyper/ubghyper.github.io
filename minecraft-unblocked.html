Playing multiplayer — servers, accounts, and what actually works

This is where browser Minecraft gets confusing, so here it is plainly. There are two different kinds of server, and they have different requirements.

Eaglercraft servers — free, no account needed

Eaglercraft has its own server network, and you can join it from the browser with no Microsoft account and no sign-up. Open a version above, go to Multiplayer, and add a server address such as xena.mc. That is the whole process. These servers run survival, creative, minigames and PvP, and they are the fastest way to play with other people at school.

Regular Java Edition servers — needs an account and a tunnel

Joining a normal online-mode Minecraft server (the kind you'd join from the desktop launcher) is harder, because browsers cannot open raw TCP connections and online-mode servers require a genuine Mojang/Microsoft login. Two things are needed:

  • A Microsoft account that owns Minecraft Java Edition. Online-mode servers verify ownership — there is no way around this, and anyone claiming otherwise is selling something.
  • A tunnel to carry the connection. The browser talks WebSocket; the server speaks raw TCP. Something has to translate between them, which is what HyperTunnel does — it's built by us and designed for locked-down school networks. From $4/month with a 3-day money-back guarantee.

If you just want to play Minecraft with friends and don't own the game, stick with the Eaglercraft servers above — they're free and they work.

Which version should you play?

  • Minecraft 1.12.2 — the best default. Newer blocks, mobs and world generation, full survival and creative. Pick this unless you have a reason not to.
  • Eaglercraft 1.8.8 — the classic PvP version. Lighter, so it's the better choice on an older or low-RAM Chromebook, and it's what most minigame servers still run.
  • Pocket Edition — the mobile-style version, good with a touchscreen.
  • Minecraft Classic — the original 2009 creative-only version. Tiny, instant, no survival.

Does it work on a school Chromebook?

Yes, and that's the point of running it in a browser. There's no installer, no launcher and no Java runtime — it's a web page, so managed Chromebooks that block downloads and app installs can still run it. Eaglercraft is demanding for a browser game, so on older hardware use 1.8.8, turn the render distance down, and close other tabs.

Your worlds are saved in the browser's local storage on that device. They survive closing the tab, but they don't follow you to another computer, and clearing browsing data will delete them. Use the in-game world export if you want a backup.
